# Корневые проверки

Папка хранит проверки внешней оболочки всего репозитория. Python-компонент
`diffusion/code` сохраняет собственные unit, contract и integration группы;
сюда не переносятся их научные тесты.

## Содержимое

- `launcher/` — наблюдаемые проверки корневого `./distil3d` через маленький
  fake Docker внутри образа `cpu-test` и сценарий настоящего жизненного
  цикла Linux/Docker.
- `support/` — повторно используемая подготовка входов и подмены внешних
  команд; научные вычисления и утверждения тестов сюда не выносятся.

Новый корневой набор добавляется только для границы, которая не принадлежит
одному компоненту. `./distil3d test all` собирает образ, выполняет внутри
него весь CPU pytest с fake Docker и затем запускает на host настоящий
`test_lifecycle.sh`. Группа `integration` включает также корневой
`launcher/test_distil3d.py`: объединение трёх отдельных CPU-групп совпадает
с Python-набором `all`, без повторного запуска одного файла.
Проверки с явным marker `native_api` требуют отдельных
production-prefix и не входят в дешёвый CPU gate. Их обязательный выпускной
прогон описан в плане Stage 9; test all не собирает production-образы.
