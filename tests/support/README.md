# Поддержка тестов корневого launcher

Папка содержит только исполняемые подмены внешних host-команд для
`tests/launcher/test_distil3d.py`. Они фиксируют вызовы и возвращают явно
заданные тестом факты; production launcher их не импортирует и не запускает.

- `fake_docker` изображает минимальную наблюдаемую поверхность Docker CLI;
- `fake_git` по явным переменным теста изображает чистый или грязный checkout,
  а в остальных случаях передаёт вызов системному Git.
- `fake_nvidia_smi` возвращает управляемую тестом карту A100/MIG без доступа
  к настоящему GPU;
- `distil3d_acceptance.py` содержит только повторяющуюся подготовку входов,
  чтение summary и отправку сигнала для acceptance-тестов; assertions в нём
  нет.

Новая подмена добавляется сюда только когда несколько launcher-сценариев
используют одну и ту же внешнюю команду.
