# Сбор результатов DDW fit

`run.yaml` запускает `waymo_ddw_fit_collection/v1` на CPU через `./distil3d`.
Выборка содержит полный keyset и только явно перечисленные новые item
records. Каталоги и condition NPY не открываются, модели не запускаются.

`collection.json` сохраняет accepted/rejected в порядке полной оси и
перечисляет отсутствующие индексы. Неполный набор помечается `incomplete`,
но корректно завершённая операция сбора возвращает код 0. У каждого
результата остаётся его исходный `item_record`; payload отсчитывается от
папки именно этого record, не от папки collection.

Личные ссылки находятся в `selections/local/`. Новые формы добавляются
только для конкретного порядка, без поиска и автоматического повторения.
