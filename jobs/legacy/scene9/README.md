# Исторические опыты Scene9

Формы используют существующие `gaussian_generation/v1–v5`, а не новые
алгоритмы. Они отделены от малых синтетических `jobs/acceptance/`.

| Задание | Порядок | Выборка |
| --- | --- | --- |
| `full-sequence` | v1, авторегрессионная последовательность | Полный экспорт Scene9 |
| `one-independent-clip` | v2, один независимый клип | ID 1 как явный представитель |
| `all-independent-clips` | v2, независимые клипы | ID 1, 2, 3, 4 |
| `dense-independent` | v3, независимые части | Исходные pose ID 0..477 включительно |
| `dense-overlap21` | v4, части с контекстом | Тот же полный исходный диапазон |
| `dense-png-handoff` | v5, PNG из двух готовых результатов | Dense ID 0,5,…,4770 |

Для первых пяти заданий оператор подключает существующий полный экспорт
`scene9-full-native-left1-v1`: `v3-refined`, камера
`/camera/inner/frontal/middle`, сдвиг `left_1.0`, все 478 исходных поз.
В этих формах его JSON-описание расположено относительно `/data`:
`gaussian/scene9-full-native-left1-v1/manifest.json`. Это прежний файл
экспортёра, новый манифест не создаётся. Dense-задания дополнительно получают
исходные `v3/9` transforms/intrinsics в `gaussian/scene9-camera-table/`.
Если данные подключены иначе, меняются эти поля в личной копии задания.

`source_pose_range` относится к физическим `pose_index` полного экспорта,
не к 383 позициям его старой 24-fps выборки. Диапазон 0..477 следует из
полного экспорта всех 478 поз; к произвольному частичному экспорту он не
применяется. Коэффициент 10 даёт 4771 dense-камеру; capacities существующих
рецептов дают 40 independent и 48 overlap частей. Handoff выбирает 955 ID.
Эти размеры описывают конкретный опыт, не универсальные ограничения кода.

Рецепты переиспользуются без копирования: seed=0, 35 шагов. Исторически
независимые клипы также запускались на 60 шагах; такой вариант выражается
изменением `generation.num_steps` в отдельном рецепте/личном задании, а не
новой версией конвейера. CP2 — нынешний принятый режим, а не заявление,
что старый CP1 pilot выполнялся на двух картах. Для v4 выбирается образ
с MoGe; v5 работает в режиме `cpu_test` без генерации моделью.

```bash
./distil3d plan --profile profiles/local/my-server jobs/legacy/scene9/dense-independent
./distil3d run --profile profiles/local/my-server jobs/local/my-scene9-job
```

Перед v5 в личной копии `run.yaml` задаются две точные завершённые попытки
`independent_attempt` и `overlap_attempt`, заменяя `replace-run` и
`replace-attempt`. Автоматического поиска latest или подбора результатов нет.
Сначала материализуется independent, затем overlap; новый reader со стороны
3dgs здесь не появляется. Формат обмена описан в
[contracts/3dgs-diffusion](../../../contracts/3dgs-diffusion/README.md).

Новые подпапки добавляются только для реально отличающегося исторического
сценария, а не для каждой комбинации сервера, параметров и запуска.
