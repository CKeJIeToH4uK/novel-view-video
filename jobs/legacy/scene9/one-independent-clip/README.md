# Scene9: one-independent-clip

Один явно выбранный независимый клип: ID 1. Это представитель, а не утверждение, что все исторические одиночные запуски использовали только его.

Вход — [run.yaml](run.yaml), параметры переиспользуют существующий рецепт
Gaussian v2. Общие данные, порядок запуска и границы исторического
воспроизведения описаны в [родительском README](../README.md).

Изменения личного опыта делаются в копии задания под `jobs/local/`;
новые файлы здесь добавляются только для отдельного сохраняемого сценария.
