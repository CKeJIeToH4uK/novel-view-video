# Исторические задания EUVS

Четыре папки связывают сохранённые выборки `selections/euvs/` с готовыми
рецептами `recipes/euvs-generation/`: `primary35`, `extended16`,
`raw29` и отдельная `location-2-tr2-to-tr6`.

В каждой папке `source-views/run.yaml` подготавливает геометрию,
`run.yaml` выполняет авторегрессионную генерацию v1, а
`source-reseed/run.yaml` — генерацию v2 с повторным началом от исходных кадров.
Оба варианта генерации используют одну явно выбранную source-views attempt;
оператор заменяет `replace-run` и `replace-attempt` реальными значениями.
Набор данных `euvs` доступен через профиль машины.

Основная метрика относится к primary35. Extended16 и raw29 запускаются и
публикуются отдельно; raw29 не объединяют с другими выборками. Оценка и
сравнение переиспользуют формы `jobs/acceptance/euvs-evaluation-run-v1`
и `jobs/acceptance/euvs-base-tuned-comparison-v1` с той же выборкой и
явными ссылками на соответствующие попытки.

Новые папки добавляются только для отдельной необходимой исторической формы,
с кратким README и ссылкой на существующий рецепт.
