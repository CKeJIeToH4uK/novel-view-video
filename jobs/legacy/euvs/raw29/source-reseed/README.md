# EUVS raw29: генерация v2

`run.yaml` использует `euvs_generation/v2`: каждое окно начинает
генерацию от исходных кадров. Пары, токены, seed и число шагов заданы общей
выборкой и существующим рецептом.

Оператор подставляет точную attempt завершённого задания
`euvs-raw29-source-views-v1` в `input.source_views_attempt`.
Порядок запуска, оценки и раздельной агрегации описан в родительском README.
Папка хранит только этот вариант; общий рецепт здесь не дублируется.
