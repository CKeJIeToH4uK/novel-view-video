# Геометрия исходных кадров EUVS raw29

`run.yaml` использует `euvs_source_views/v1` и существующий рецепт
VGGT Omega для выборки `selections/euvs/euvs-setting1-raw29.yaml`.
После завершения точная ссылка на attempt задания `euvs-raw29-source-views-v1`
передаётся одному или обоим вариантам генерации из родительской папки.

Папка хранит только подготовку этой выборки; новые варианты добавляются
при изменении научной задачи, без копирования модельного рецепта.
