# Исторические задания

Здесь сохраняются конкретные опыты, запускаемые существующими версиями
конвейеров через корневой `./distil3d`.

- `euvs/` разделяет исторические выборки и source views / generation;
- `scene9/` задаёт шесть исторических Gaussian-сценариев;
- `waymo/` хранит прежние центральные keysets, трёхкамерное сравнение
  глубины и отдельные решения v1/v2; настоящие ключи и reports остаются в
  исключённой из Git `selections/local/`.

Научные параметры переиспользуют `recipes/`, пары и камеры — `selections/`.
Новый сценарий добавляется с работающим разбором задания, коротким README
и строкой миграции. Данные, модели и результаты сюда не копируются.
Личные пути и точные номера запусков указываются в копиях `jobs/local/`.
