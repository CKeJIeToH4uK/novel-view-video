# Примеры задач

Папка содержит маленькие переносимые jobs, которые демонстрируют уже
работающий пользовательский путь без данных, моделей и секретов.

- `lifecycle-smoke/` — внутренний синтетический срез launcher lifecycle.
- `r4c-select-v1/` и `r4c-select-v2/` — формы выбора из явно перечисленных
  checkpoint records;
- `r4c-ddw-evaluation/` — форма matched base/v1/v2 оценки одного шага.

Пример не становится шаблоном произвольного shell-запуска: workflow и его
поля должны иметь конкретного владельца в `novel_view`.
