# Пример matched DDW evaluation

`run.yaml` показывает форму `ddw_evaluation/v1`. Перед реальным запуском
папку копируют в `jobs/local/` и подставляют точные записи v1/v2 одного
фактического `completed_step`. Пример предназначен для `plan`; он не ищет
готовые запуски и не выдаёт вымышленные пути за существующие.
