# Примеры профилей

Каждая подпапка содержит отслеживаемый `.env.example` для одного реально
тестового режима или явной аппаратной цели и короткое объяснение. Пример копируется в
`profiles/local/<name>/.env`; реальные пути в исходном файле не сохраняются.

- `cpu-test/` — проверенный режим без GPU;
- `a100-4gpu/` — цель первой аппаратной приёмки; настоящая проверка Stage 11
  пока не выполнена.

Новый профиль добавляется вместе с конкретным режимом, а его аппаратная
готовность отмечается отдельно. Название сервера, пользователь и секреты
в примеры не попадают.
