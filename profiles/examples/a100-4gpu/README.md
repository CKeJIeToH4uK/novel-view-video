# Аппаратная цель: четыре A100

Пример задаёт пять внешних каталогов и порядок доступных устройств.
Скопируйте `.env.example` в `profiles/local/my-server/.env` и замените пути
и GPU IDs. Вместо чисел допустимы UUID устройств, в том же порядке.

CP1 использует первый ID, CP2 — первые два, CP4 — первые четыре. Внутри
контейнера они получают индексы `0..N-1`; CPU-задача не подключает GPU.
План только показывает это назначение и не проверяет сами устройства.

Реальная работа на A100, включая NCCL и CP4, принимается отдельной финальной
кампанией Stage 11. Наличие этого примера не означает пройденный аппаратный
тест. Имена серверов, пользователей, настоящие пути и секреты сюда не добавлять.
