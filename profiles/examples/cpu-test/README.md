# Профиль CPU-контура

Этот пример предназначен для host-диагностики и CPU-задач в готовых образах.
GPU не требуется, поэтому `DISTIL3D_GPU_IDS` оставлен пустым.

Скопируйте `.env.example` в `profiles/local/cpu-test/.env` и замените пути на
существующие каталоги своей машины. Команда `doctor host` только показывает
data/models roots и проверяет малой временной записью prepared/runs/cache.
