# Профили машин

Профиль описывает только локальные ресурсы одной машины. Пользователь копирует
подходящий пример в игнорируемую Git папку `profiles/local/<name>/.env` и
подставляет абсолютные host-пути.

Поддерживаемая грамматика намеренно мала: пустые строки, отдельные строки с
комментарием и `KEY=VALUE`. Значение — весь текст после первого `=`. Файл не
исполняется как shell: подстановки, команды, кавычки и inline-комментарии не
интерпретируются.

Обычное чтение требует ровно по одному экземпляру каждого из шести известных
ключей и запрещает неизвестные. `DISTIL3D_GPU_IDS` — пустая строка либо
упорядоченный список числовых Docker ID или GPU UUID через запятую без
пустых элементов и повторов. GPU-preset выбирает первые 1/2/4 устройства;
слишком короткий список даёт ошибку до создания attempt. CPU-preset не
использует устройства, даже если они перечислены. Внутри GPU-контейнера
видимые индексы — `0..N-1`, а не исходные host ID.

При обычном чтении профиля наличие и занятость GPU не проверяются.
Явный `./distil3d doctor host` проверяет запись в prepared/runs/cache и
место, а data/models только показывает. Читаемость data/models проверяет
foundation финальной приёмки; `doctor job` открывает входы выбранной задачи.
Обычные команды не получают скрытую диагностику.

- `examples/` содержит безопасные отслеживаемые образцы;
- `local/` полностью исключена из Git и предназначена для настоящих путей.

Данные, модели, секреты и сам локальный `.env` в Git не добавляются.
