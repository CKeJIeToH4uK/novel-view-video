# Исследования

Здесь живут короткие описания воспроизводимых исследовательских сравнений:
гипотеза, связанные tracked jobs, одинаковые условия и фактический вывод.
Машинные пути, веса, данные и полные результаты остаются вне Git.

Новая подпапка добавляется только вместе с уже существующими вариантами job.
До реального измерения документ фиксирует статус `pending` и не заявляет
улучшение качества.
