# Novel View Video

Исследовательский проект генерации новых ракурсов дорожных сцен с Gen3C:
EUVS/nuPlan и Gaussian-вход, подготовка Waymo/DDW, дообучение R4c LoRA
и оценка изображений и глубины.

Внутренний Python-пакет — `novel_view`. Все пользовательские команды
выполняются через корневой `./distil3d`.

## Статус

Это предварительная публикация исходного кода, не проверенный GPU-выпуск.
До публикации исходная версия прошла 406 CPU-тестов и проверку жизненного
цикла Docker-контейнеров на Linux. Эти результаты не доказывают качество
генерации или работу текущего снимка на A100.

- Основной путь обучения — R4c LoRA v1 с существующей топологией CP4.
- V2 с дополнительным лоссом глубины и исследовательский DA3 экспериментальны.
- Реальная приёмка этой версии на A100 ещё не проведена.
- Общая команда `accept a100-4` требует четыре A100. Однокарточного
  `accept a100-1` пока нет; изменение профиля не превращает CP4 в CP1.
- Готовые Docker-образы, модели, датасеты и результаты не распространяются.
- Код 3DGS, запекания и фиксеров не входит в этот репозиторий.
  Чтение готового Gaussian-экспорта в diffusion сохранено.

## Быстрый вход

На Linux/amd64 с Docker и NVIDIA runtime подготовьте
[профиль машины](profiles/README.md) и следуйте [инструкции](docs/quickstart.md):

```bash
git clone https://github.com/CKeJIeToH4uK/novel-view-video.git
cd novel-view-video
./distil3d build
./distil3d plan --profile profiles/local/my-server jobs/acceptance/euvs-pair-autoregressive-v1
./distil3d run --profile profiles/local/my-server jobs/local/my-euvs
```

Профиль и личную задачу нужно создать по инструкции до последних двух команд.
Примеры описывают формат входа, но не содержат реальные данные.
Данные, веса и результаты подключаются внешними каталогами; Conda
и ручной `PYTHONPATH` на хосте не нужны.

CPU-проверки на Linux: `./distil3d test all`.
Состояние текущей проверки видно во вкладке Actions.
