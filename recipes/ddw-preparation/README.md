# Рецепты подготовки DDW

Здесь находятся научные параметры `ddw_preparation`, общие для разных
машин: контракт R4c, выбранный depth backend и относительные пути к
закреплённым model assets внутри `/models`.

`r4c-moge.yaml` — единственный поддерживаемый рецепт первой версии: MoGe
строит condition depth, а установленные Gen3C T5/VAE запекают model-ready
артефакты. Выбор данных и GPU-профиля сюда не добавляется.
