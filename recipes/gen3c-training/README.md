# Рецепты обучения Gen3C

Здесь лежат научные параметры двух явных R4c LoRA-вариантов: неизменного
Kendall EDM baseline `r4c-lora-edm.yaml` и экспериментального дополнения
LiDAR-depth `r4c-lora-lidar-depth.yaml`. Пути данных и процессная топология
остаются в job и профиле, а не в recipe.

Новый recipe добавляется только для осмысленно отличающейся версии или
заранее зарегистрированного опыта и получает собственный строгий parser.
