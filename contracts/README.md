# Файловые границы компонентов

Здесь описывается уже существующий обмен независимых частей проекта.
Это документация, не новый слой исполнения, проверки файлов или схема
всех датасетов.

- `3dgs-diffusion/` описывает готовый 3DGS RGB/depth/mask export v1 и
  односторонний PNG handoff из diffusion.

Новая граница получает описание фактического производителя, читателя,
полей и единиц измерения. Существующие проверочные примеры не копируются;
документ ссылается на их единственное место в тестах. Веса и данные сюда
не добавляются.
