# Выборки Scene9

Шесть файлов соответствуют шести заданиям в `jobs/legacy/scene9/`.
Полный экспорт имеет scene_id=9; independent clips используют 1-based ID,
dense-порядки — включительный физический source pose range 0..477.
`dense-handoff.yaml` буквально хранит 955 ID 0,5,…,4770; список не строится
при запуске и не попадает в production как константа.

Диапазон доказан для полного исторического 478-frame экспорта:
производитель после выбора камеры берёт `range(len(poses))` и записывает
эти значения в `pose_index`. При другом или частичном входе оператор задаёт
свою выборку в `selections/local/`, а не расширяет эту историческую форму.
Новые файлы здесь добавляются только для конкретного сохранённого опыта.
