# Исторические выборки

`scene9/` содержит конкретные камеры и клипы сохранённых Gaussian-опытов.
Исторические EUVS пары находятся в соседней `../euvs/`, вместе с их
существующим типом входа. `waymo/` показывает один точный clip и ordered
восемь runs-relative candidate locators для depth workflows.

Новые выборки сохраняют только устойчивые ID и порядок; машинные пути,
параметры моделей и номера запусков принадлежат другим файлам.
