# Выборки EUVS

Папка хранит упорядоченные пары `schema_version: 1` без машинных путей и
модельных параметров. `one-pair.yaml` остаётся общим примером с заменяемыми
токенами. Четыре `euvs-*.yaml` перенесены из прежних experiment-конфигураций
с точным сохранением пар, тегов, якорей YAML и порядка токенов исходных и
целевых кадров.

- `euvs-setting1-primary35.yaml` — полные пары основной метрики, класс A;
- `euvs-setting1-extended16.yaml` — дополнительные полные пары класса B и
  явно обрезанные target-последовательности класса C;
- `euvs-setting1-raw29.yaml` — остальные полные комбинации для исследования
  отказов и чувствительности;
- `euvs-location-2-tr2-to-tr6.yaml` — первая историческая отдельная пара.

Это производная Gen3C-on-EUVS кампания по материализованному nuPlan-поднабору,
а не официальный PairSet или знаменатель EUVS Setting 1. Классы A/B/C
происходят из исторического плана получения данных проекта; raw29 — дополнение
его набора комбинаций, не отдельный научно отобранный класс. Причины отбора
остаются в журналах, обрезанные target-интервалы заданы самими токенами.

Основная таблица использует только primary35. Extended16 и raw29 запускают,
оценивают и публикуют отдельно; raw29 не агрегируют с двумя другими
выборками. Готовые задания находятся в `jobs/legacy/euvs/`, модельные
параметры — в существующих `recipes/euvs-generation/`.

Новые выборки добавляются явным YAML с осмысленными именами пар и точным
порядком токенов; исторический состав не пересчитывается автоматически.
