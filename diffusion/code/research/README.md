# Research

Здесь находятся запускаемые исследовательские реализации, которые не входят
в production wheel и не обещаны публичным интерфейсом проекта.

Каждый прототип живёт в собственной папке с коротким описанием границы,
научных допущений и способа запуска. Он может импортировать `novel_view`, но
production-код не импортирует `research`.
