# DA3 Nested

Замороженный исследовательский адаптер pose-conditioned DA3 Nested. Он
принимает уже подготовленные source RGB и измеренные камеры, запускает DA3 в
отдельном Python-окружении и возвращает метрическую глубину на общей
source-сетке.

- `adapter.py` содержит входной план, научные проверки камер и перевод
  результата в `PosedDepthSequence`;
- `_worker.py` вызывает закреплённый официальный DA3 API;
- `io.py` один раз записывает упорядоченный uint8 RGB во временный NPY.

Прототип запускается только явным исследовательским кодом из checkout. Он не
входит в wheel, не имеет job/CLI и не является поддерживаемым production
backend. Новые варианты сюда не добавляются без отдельного научного решения.

Исследовательский Python запускается из `diffusion/code` с установленным
`novel_view`: существующие `Da3NestedResources` и
`predict_da3_nested_geometry` импортируются из `research.da3_nested.adapter`.
Оператор явно передаёт готовый measured source pack, `process_resolution`,
Python DA3-окружения, каталог весов, временную папку и путь журнала. Адаптер
запускает соседний `_worker.py` по абсолютному пути; этому дочернему Python
не нужен import `research` или рабочая папка родителя.
