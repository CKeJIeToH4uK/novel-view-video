# Исходный код

Устанавливаемый пакет находится в `novel_view/`. В этой папке не хранятся
данные, модели, окружения, результаты запусков или сторонние репозитории.

Новые пакеты верхнего уровня добавляются только при появлении отдельной
области ответственности, которую нельзя естественно разместить в
`novel_view`.
