# Подготовка данных

Папка содержит предметные producers, которые читают конкретный внешний
источник и один раз выпускают готовые для модели артефакты. Она не владеет
обучением, оценкой, checkpoint/resume или общим workflow registry.

- `waymo_ddw/` — один поддерживаемый путь подготовки FRONT Waymo для R4c DDW;
  его `legacy/` отдельно сохраняет исторические masks/gates/canary/probe/survey;
- `waymo_depth/` — исторические central keysets и трёхкамерная подготовка
  глубины с прежними внешними records.

Новый producer добавляется отдельной предметной подпапкой только при наличии
реального потребителя. Общие reader и model adapters остаются в `inputs/` и
`models/`; зависимости направлены от preparation к ним, но не обратно.
