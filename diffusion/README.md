# Diffusion

`code/` содержит Python-компонент novel_view: входные данные, геометрию,
генерацию, обучение, метрики и отдельные тесты.
Пользователь работает из корня репозитория через ./distil3d.

- [Быстрый запуск](../docs/quickstart.md).
- [README компонента](code/README.md).
- [Архитектура компонента](code/ARCHITECTURE.md).

Модели, датасеты, окружения и результаты хранятся вне Git.
Машинные пути задаются личным profiles/local/<name>/.env.
